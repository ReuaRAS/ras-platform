# قطاع الأفواج الأمنية (SB) — فارغ عمدًا

هذا المجلد **فارغ بالتصميم**. لا يوجد أي محتوى وهمي لهذا القطاع.

## ما الذي يعمل من اليوم الأول؟

- الصفحة العامة: `/sectors/security-brigades` (تُظهر حالة "المحتوى قيد الإعداد").
- لوحة الإدارة: `/admin` تعمل بالكامل لحساب `sb@ras.internal`.
- شاشة Onboarding في لوحة الإدارة تظهر عند عدم وجود أي بيانات، مع أزرار:
  - إضافة أول دورة
  - إضافة أول قانون
  - إضافة أول مكافأة

## كيف يُضاف المحتوى؟

1. الدخول إلى `/admin` بحساب القطاع.
2. إضافة أول قانون أو مكافأة → يُستدعى تلقائيًا `seed_sector_defaults`
   لنسخ القوانين والمكافآت الأساسية من القطاع المرجعي (`red-crescent`).
3. إضافة الدورات والأسئلة من `/admin/courses` و`/admin/tests`.
4. ربط الأسئلة بالاختبار وتحديد `certificate_prefix` حسب القسم 15 من المواصفة.

## إضافة قطاع جديد مستقبلًا

لا يحتاج القطاع الجديد أي تعديل على الكود:

```sql
insert into public.sectors (slug, name, sector_code, primary_color)
values ('new-sector', 'اسم القطاع', 'NEW', '#123456');
```

ثم إنشاء حساب إداري عبر `supabase.auth.admin.createUser` مع
`app_metadata: { sector_slug: 'new-sector', role: 'sector_admin' }`،
ويظهر القطاع تلقائيًا في الصفحة الرئيسية ولوحة الإدارة.
